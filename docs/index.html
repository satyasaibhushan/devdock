Every dev pod, on every machine, in one place.

devdock is an always-on daemon over devspace, kubectl and tmux. It shows which machine owns each deployment, streams its logs and dev terminal, and runs ticket sandboxes that sleep when idle and restore from their last images. Agents drive the same verbs over MCP.

  • start devspace dev
  • build devspace deploy
  • kill devspace purge
  • listen tmux attach -r
  • attach tmux attach

Owned, not guessed

Each workload records the machine that deployed it. Moving it to another machine is a planned release and start, and a second machine cannot take it while the owner answers.

Sandboxes per ticket

Members build from a checkout, uncommitted files included. A successful build snapshots the images, so an expired sandbox restores without rebuilding.

State from the cluster

The daemon reconciles against live kubectl output, so it adopts pods it never started. Dev sessions live in tmux and outlive daemon restarts.

Run it

Needs Node 20+, pnpm, and devspace, kubectl and tmux with a working kube context. It installs from a checkout; there is no packaged release.

The demo daemon needs none of that.

# the real thing, on :7717
pnpm install && pnpm build
pnpm dev

# the demo above, on :7799
pnpm --filter @devdock/web build
pnpm --filter @devdock/daemon exec tsx demo/fixtureDaemon.ts
